# 📦 TEMPLATE PACCHETTO DI MANIFESTAZIONE

Usa questa cartella per creare una nuova manifestazione da inviare a Mirror Mountain OS:

1. **Duplica questa cartella** e nominala con il numero e il nome della tua entità (es. `02_STRONGBOX_X`, `03_AVATAR_ROOM`, `04_RITUAL_CHEST`).
2. **Incolla il tuo modello 3D** (`.glb`) esportato da Nomad Sculpt o Blender e rinominalo (es. `strongbox.glb`).
3. **Modifica `essence_template.json`** impostando il nome del file `.glb`, la frequenza in Hz (es. 528 Hz), e le impostazioni economiche/rituali.
4. **Aggiorna `intento_template.md`** con la descrizione narrativa della sequenza VR.
5. Se hai un'interfaccia o logica web interattiva, inseriscila nella cartella `web/` (`index.html`, `app.js`, `style.css`).
6. Fai doppio clic sul collegamento sul Desktop:  
   `INTERDIMENSIONAL ALPHABET.lnk`
7. Mirror Mountain OS leggerà la cartella, verificherà con Uniform Guardian e proietterà l'esperienza!
